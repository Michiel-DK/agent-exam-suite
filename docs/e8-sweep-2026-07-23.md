## Findings that survive the noise band

1. **gemma4:e4b-it-qat is the standout, and low-risk.** e4b sibling of the e2b champion
   (same family/quant/deployment profile). crm **4/4 + 3/3 train** — the **only** model to
   pass `two-tool-combo`, the case the crm champion fails deterministically (0.0). That case
   needs a second tool call (`deals_list`) chained — a real capability the champion lacks.
   **Single most meaningful delta in the sweep.** Matches or beats champion on all 4 exams.

2. **qwen3:8b: expense 5/5 + 5/5 train** (perfect, beats champion 4/5). Slower, and see (3).

3. **Multilingual / Portugal signal (weak, real):** no PT case exists yet. The language-match
   check caught **qwen3:8b replying in Dutch to an English email** (`budget-figure-demand`).
   The 100+-lang models are capable but over-eager to switch — E14 must make language-match a
   *guarded* check, not an assumption. Feeds [[operator-market-portugal]].

## Instrument findings (arguably the bigger result)

- **2 of 4 exams no longer discriminate.** email-triage heldout is saturated (everything 4/4);
  reply-draft is judge-noise-dominated (Step 0 confirms the F3 caveat *live*, not theoretical).
  A self-improvement loop against these two would optimize to noise. **Stronger heldout for
  email-triage + a judge fix/swap for reply-draft are prerequisites, not enhancements.**
- **The missing operational piece is an automated noise-band analyzer.** The band→genuine-delta
  reasoning in this doc was done by hand. To make the sweep an unattended nightly, that has to
  become code (read `results/` + Step-0 flaky set → emit genuine-win / in-band / regression).
